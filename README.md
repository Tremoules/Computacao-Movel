# Computação Móvel

Coursework repository for **Mobile & Ubiquitous Computing (Computação Móvel)**, academic year **2026–2027**.

## About the Course

This course explores the characteristics and development processes of mobile computing systems from an information systems perspective. Its primary objective is to develop the skills required to design and build services and applications for mobile devices.

Topics covered include:

- Design, development, prototyping, and evaluation of mobile applications
- Mobile devices, including smartphones and tablets
- Mobile operating systems, with an emphasis on Android
- Mobile networks and information technologies
- Interface capabilities, interaction modes, and technological limitations
- Social and cognitive contexts of mobile technology use
- Distributed and multimodal application development
- Data management in Android applications

Throughout the course, the assignments apply these principles, techniques, and methodologies through practical Android projects.
